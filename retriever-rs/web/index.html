Connections & clients

Install the same client on Windows, Linux or macOS. Connect it to the main PC through HTTPS or a private SSH tunnel. Every client uses the main PC's index and models.

Install a client on another device

Extract the public source package on that device, then run:

python install.py --role viewer --endpoint http://127.0.0.1:18769
ssh -N -L 127.0.0.1:18769:127.0.0.1:18780 main-pc

Use a pinned SSH host key. Add a main-pc SSH alias and verify its host key first. Enter the main PC's private pairing token in the client. Add --desktop to the installer for the native desktop shell. SSH collectors need no AI models.

Private app tunnel

Reach a service running on a connected device's loopback address. The local port is available only on this PC. Start the remote service separately.

Shared folders are named locations in this authenticated workspace. They are available to your paired clients; this does not create an SMB/NFS mount or anonymous public link. All paired clients are trusted operators with the same selected-folder access.

How will you use Retriever?
Choose the main PC to manage your shared index and built-in search models in one place.






Use HTTPS for a shared address, including Tailscale HTTPS. A local SSH tunnel can use loopback HTTP. The server binds locally; sharing requires your existing tunnel or proxy.



Your devices
Each source has its own folder selection. SSH devices use your existing keys and known_hosts.






Prepare a device for SSH access
Enable its SSH server, install the matching reviewed Retriever agent, and add a Host alias to your SSH config on this PC. Verify its host key and key-based login in your terminal before testing here.
Host my-device

    HostName device.example.ts.net

    User your-user

    IdentityFile ~/.ssh/id_ed25519
Test with ssh my-device. Retriever uses your existing keys and verified host keys. Sources use the Rust agent and packaged extraction tools; no AI models are needed there.
Use “Test connection” to verify the matching Rust agent over SSH. Device migration and agent installation require review. No AI models are installed on sources.



Choose what to search
Choose a device, then browse its folders to include or exclude them. You can also enter paths and exclusion patterns.






Local search engine
EmbeddingGemma finds passages by meaning. Laya checks the relevance of shortlisted results. Both models run inside Retriever on the coordinator.
Indexing limits and result count
Collection continues in bounded batches until every selected folder is scanned. File and extracted-text limits apply to individual files. PDF content that needs a password or repair remains searchable by filename with an explicit warning.
EmbeddingGemma · meaning search
Built in. Selected files are extracted into the local catalogue and indexed in reusable batches.
Laya · relevance ordering
Built in. Exact searches preserve their order. Uncertain decisions preserve retrieval results.
Models, cached passages, vectors and metadata live together in the application data folder. Original files stay in the folders you selected.
Models and indexing run on your coordinator.

Devices and indexing
The index stays on your main PC. EmbeddingGemma and Laya run locally. A scan reads selected folders; a meaning rebuild uses their last collected text.




Folder sync
Two folders, one reviewed flow. New files travel both ways. Updates retain previous versions; conflicting edits preserve both originals. Deletions stay local. All transfers pass through your main PC.
Connect a folder pair
Start with smaller project folders. Each side supports up to 1,000 files / 128 MiB per comparison; a reviewed sync supports 100 transfers. Excluded and protected paths stay excluded.


Review sync
Previous and conflicting copies live in the pair’s Retriever Versions folder. Originals are never permanently deleted. This review expires in ten minutes or when settings/files change.


Install a desktop client
A dedicated Retriever app on every device. Download a native installer below, or install over SSH from Remote install. Linux has desktop and headless clients. The source-install command remains available for development. Models run inside the coordinator. Clients need no model setup.
Installation paths
Existing data paths are reused. Reinstall with the same app/data paths to update. Uninstall the app folder and its launcher; keep your data folder to retain pairing, settings and the main PC’s index/models.
